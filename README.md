# 🏥 360°深耕奇美・永續醫療｜健康台灣深耕計畫 共識營互動網頁

參加者用手機掃 QR Code 報到、選一位醫療專業「捏捏人」、隨機抽到 01–06 其中一張詞卡並填寫。
全場的詞會拼成一句句跨職類的行動句，在島上長出幼苗，再由大家澆水，選出共識大樹。

## 三個頁面

| 頁面 | 給誰用 | 用途 |
|---|---|---|
| `index.html` | 參加者手機 | 報到、選人物、抽卡、填寫、澆水、探索島嶼 |
| `screen.html` | 投影大螢幕（3D 版） | 立體360°深耕奇美：人物在島上走動、政策索引、協作線、晝夜切換、QR Code、揭曉聚光、澆水大樹、收成排名 |
| `screen-lite.html` | 投影大螢幕（簡易版） | 平面版島嶼，給效能較弱的電腦當備案，功能相同 |
| `host.html` | 主持人（筆電或平板） | 切換階段、拼句、聚光輪播、島嶼導覽、匯出 CSV、彩排模擬 |

主持人密碼預設 `0000`，在 `js/config.js` 修改。

## 一、先在自己電腦試玩（示範模式，免設定）

`js/config.js` 的 `firebase` 保持 `null` 時，會進入「本機示範模式」：
同一台電腦、同一個瀏覽器的分頁之間會即時同步。

1. 用 Chrome 開啟 `host.html`，輸入密碼 `0000`
2. 點「開啟大螢幕」與「開啟參加者頁」
3. 在主持人頁「彩排工具」輸入人數，按「加入並自動填寫」
4. 依序按「揭曉 → 下一句 → 澆水 → 模擬澆水 → 收成」看完整流程

> 示範模式不能跨手機同步。正式活動請完成下面第二、三步。

---

## 二、建立 Firebase 即時資料庫（約 10 分鐘，免費）

1. 到 <https://console.firebase.google.com> 用 Google 帳號登入，點「新增專案」，名稱例如 `deepisland`（Google Analytics 可關閉）
2. 左側選單「建構 → Realtime Database」→「建立資料庫」
   - 位置選 **新加坡（asia-southeast1）**，離台灣最近
   - 安全規則先選「以鎖定模式啟動」
3. 進入資料庫的「規則」分頁，把本資料夾的 `database.rules.json` 內容整份貼上，按「發布」
4. 回到「專案總覽」，點網頁圖示 `</>` 新增網頁應用程式（名稱隨意，不用勾 Hosting）
5. 畫面會出現一段 `firebaseConfig = { ... }`，把它貼到 `js/config.js`：

```js
firebase: {
  apiKey: "AIza....",
  authDomain: "deepisland-xxxx.firebaseapp.com",
  databaseURL: "https://deepisland-xxxx-default-rtdb.asia-southeast1.firebasedatabase.app",
  projectId: "deepisland-xxxx",
  appId: "1:..."
}
```

> ⚠️ 一定要有 `databaseURL`。如果 firebaseConfig 裡沒有，請到 Realtime Database 頁面上方複製網址貼上。

## 三、部署到 GitHub Pages

1. 在 GitHub 建立新的 repository（例如 `deepisland`），可設為 Public
2. 把整個資料夾的檔案上傳（`index.html` 要在最外層）
3. repository 的「Settings → Pages」，Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`，儲存
4. 約 1 分鐘後會得到網址，例如 `https://你的帳號.github.io/deepisland/`
   - 參加者：`.../deepisland/`（大螢幕會自動產生這個網址的 QR Code）
   - 大螢幕：`.../deepisland/screen.html`
   - 主持人：`.../deepisland/host.html`

## 四、活動當天建議流程（約 30–40 分鐘）

| 階段 | 主持人操作 | 現場畫面 |
|---|---|---|
| 0. 開場導覽 | 「島嶼導覽」依序點範疇一～四、所有關聯 | 大螢幕顯示各範疇子項目與跨範疇關聯 |
| 1. 報到填寫 | 階段選「報到填寫」 | 大家掃 QR 報到，人物陸續出現；填完的人頭上有發光種子 |
| 2. 揭曉 | 按「拼句，長出幼苗」→ 階段選「揭曉」→「下一句」或「自動輪播」 | 六位作者的藤蔓連到幼苗，下方顯示完整句子與六人的職類 |
| 3. 澆水 | 階段選「澆水」 | 每人 3 滴水，大樹即時長大 |
| 4. 收成 | 階段選「收成」，按「句子與票數 CSV」匯出 | 大螢幕顯示共識前五名 |

**拼句規則**：系統派卡時會讓 01–06 各欄人數平均；拼句時每句盡量由不同職類組成，
每個人的詞至少會出現在一句裡（人數不平均時，少數詞會被重複使用來補齊）。
句子的範疇採多數決，其他範疇會以藤蔓連到對應區域，這就是「大家長出來的連線」。

**正式開始前**：在主持人頁按「重置整場活動」，清除彩排資料。

## 3D 大螢幕操作

- **滑鼠**：左鍵拖曳旋轉、滾輪縮放、右鍵拖曳平移；點地塊名稱會飛過去並顯示說明
- **右側索引**：點範疇會飛到該範疇並顯示跨範疇協作線；「協作關係」分頁列出所有關聯
- **工具列**：清晨／白天／黃昏／夜晚、名牌開關、漫遊（自動緩慢旋轉）、協作線、暫停走動、鳥瞰、日誌
- **右上**：全景（回到預設視角）、清單（收合右側索引，畫面更大）、說明
- 場景採風格化的古典博物館園區（原創建築，未使用任何博物館標誌或照片）：中央「深耕殿」宮殿與前庭噴泉，四大範疇是大理石展台，外圍是草坪與環形湖
- 主島以八座有雕像與路燈的石橋跨湖連到外圍八座圓頂涼亭（照護八站），外圍是一整圈連續的列柱迴廊，金色箭頭標示 1→8→1 的照護循環
- 人物報到會從天而降落在中央廣場；種下詞之後，會走到自己選的範疇島上散步
- 揭曉時，鏡頭飛到幼苗，六位作者會走到幼苗旁圍成一圈，頭上的光點沿著藤蔓流向幼苗
- 主持人頁的「島嶼導覽」會同步控制 3D 鏡頭

> 3D 版需要電腦有基本的顯示卡效能（一般近 5 年的筆電即可）。投影電腦若感覺卡頓，改開 `screen-lite.html`，資料完全共用。

## 五、修改內容

- `js/content.js`：願景、照護八站、四大範疇與子項目、政策關聯（`links`，目前為依圖面推論的暫定版）、六欄題目與參考詞
- `js/config.js`：活動標題、密碼、每人水滴數、活動代號、Firebase 設定
  - 想辦第二場：把 `eventId` 改成新代號（例如 `camp2026b`），資料就會分開
- `js/avatars.js`：50 種捏捏人（手機選角用的平面版）；`js/life3d.js`：同一批人物的 3D 版
- `js/world3d.js`：3D 島嶼的地塊、各子項目的場景、照護八站小島

## 六、注意事項

- **連線數**：Firebase 免費方案同時連線上限 100，70 位參加者加大螢幕、主持人沒問題
- **網路**：建議現場準備備用熱點；斷線時手機會顯示提示並自動重連
- **名字會公開顯示在大螢幕**，請提醒大家可以用暱稱
- **資料安全**：為了免登入，資料庫規則允許知道網址的人讀寫。活動結束匯出資料後，建議到 Firebase 刪除 `events` 資料，或把規則改回鎖定
- QR Code 產生器（`js/vendor/qrcode.js`）與 3D 引擎 Three.js（`js/vendor/three.min.js` 等）都已內建，MIT 授權，不依賴外部服務

## 院區場景說明（3D 版）

- 場景參考奇美院區各大樓的相對位置，以原創風格化 3D 造型呈現，不使用醫院標誌或實際照片
- 中央：第二醫療大樓（願景・照顧台南一輩子），前方是「永續廣場」噴泉，新報到的人物會降落在這裡
- 範疇一：第一醫療大樓｜範疇二：教學大樓｜範疇三：研究大樓｜範疇四：第五醫療大樓＋第三醫療大樓
- 17 個子項目是各大樓前的圓形展台；停車場改成三座「行動廣場」，揭曉後幼苗種在這裡
- 外圍一圈是「360° 永續照護環」，八個照護站以空橋跨越中華路、採購大道、大武街連回院區；步道遇到道路時會架高成天橋
- 大樓位置、對應範疇在 `js/world3d.js` 開頭的 `BUILDINGS`、`STATIONS`、`PLAZAS` 修改

## 手機「找到我的人物」

參加者送出詞之後，手機會出現「🗺️ 看院區地圖，找到我的人物」按鈕，點下去會開啟手機版 3D 院區：
鏡頭自動飛到自己的人物並跟著走，腳下有金色光圈、頭上有金色箭頭，名牌標示「📍我」。
下方工具列可切換「跟著我／全景」，或回到詞卡頁。此模式只看不控制，不會影響大螢幕。

## 效能說明

- 參加者手機平常只開輕量的報到頁（2D），不跑 3D；只有點「找到我的人物」才會開 3D 地圖，且手機上會自動關閉陰影、降低解析度
- 大螢幕 3D：以 70 人實測，每一格畫面的程式運算約 2 毫秒、約 350 個繪製批次，一般近 5 年的筆電顯示卡可順跑
- 自動效能保護：若大螢幕連續 4 秒低於約 28 fps，會自動關閉陰影並降低解析度
- 資料同步使用 Firebase 即時資料庫，只傳送變動的部分；免費方案同時連線上限 100（70 支手機＋大螢幕＋主持人約 72～80 條）

## 2026-10 改版：流程與場景

**參加者流程（手機）**
1. 選一位捏捏人，填「部門」與「姓名或暱稱」
2. 選一個想深耕的範疇（一～四），人物會走到該範疇的大樓前
3. 六欄全部填寫：主詞、動詞、受詞、合作夥伴、方式、目的（每欄都有建議詞可點選，上方有依範疇顯示的參考範例句）
4. 種下行動句：在「社會情緒學習廣場」或「復原力廣場」隨機開出一朵彩色花
5. 揭曉時看大家的行動句；澆水時每人 3 滴水投給最想實現的句子

**主持人後台**
- ① 挑選與修改：所有完成的行動句都列出來，可直接點文字修改（↺ 還原）、勾選要展示的句子、設定展示數量並「依範疇平均挑選」
- ② 揭曉清單：用勾選的句子產生清單，上一句／下一句／自動輪播，鏡頭會飛到作者身邊
- 匯出：揭曉句子與票數 CSV、全部行動句明細 CSV（含部門、六欄、是否修改）、完整備份 JSON

**共識大樹**
- 進入「澆水」或「收成」後，大螢幕自動切換成全螢幕的指紋共識大樹；工具列的「大樹」按鈕可手動切換回 3D 院區
- 從一顆種子開始：發芽 → 長出樹幹 → 枝條逐層展開 → 指紋葉逐片長滿；全場累積「報到人數 × 1」滴水就長成滿樹（5 人 5 滴、70 人 70 滴，可在 `js/config.js` 的 `treeDropsPerPerson` 調整；超過也沒關係），下方有進度條與「再 N 滴長成大樹」；每次有人澆水，畫面會落下水滴；揭曉的句子是樹上的彩色果實（顏色＝範疇），票越多越大、越靠近樹頂中央
- 右側即時顯示排行，收成時顯示前五名

**3D 院區**
- 人資碼頭與人資船移除，改為 7 顆印有 CHIMEI 字樣的人資熱氣球，在院區上空巡航，不定時空投撐著降落傘的人力到各範疇展台支援
- 行動廣場 B、C 改為「社會情緒學習廣場」「復原力廣場」，每完成一句行動句就開一朵花
- 已移除舊的平面版大螢幕（screen-lite.html）

## 院區直播（大螢幕右下）

像直播聊天室一樣即時跳出院區動態（最新 5 則，左側色條區分類型）：
- 參加者報到、種下行動句開花
- 🎈 人資熱氣球「派送人力，支援範疇○」
- 🚐 資訊車停靠照護站時，輪流回報範疇三（導入智慧科技）建置進度：建置 FHIR 中、導入智慧平台、AI 協助臨床上線測試…
- 🛥️ 會計船靠岸會計碼頭時，回報「已完成範疇○核銷 ✅」

訊息文字可在 `js/content.js` 的 `live` 修改（資訊車的建置項目清單可自行增減）。

## 點花看是誰寫的

大螢幕和手機地圖上，點「社會情緒學習廣場」「復原力廣場」裡的任何一朵花（或院區裡的任何人物），會跳出說明卡：作者人物、姓名、部門、範疇，以及完整的行動句（主持人修改過的會顯示修改後的版本）。
手機地圖下方有「🌸 花園」按鈕可以直接飛到花園；手指拖曳畫面時會自動停止「跟著我」，方便自由逛。

## 主持人頁：共識大樹預覽

主持人頁最下方有「🌳 共識大樹預覽」，依目前報到人數即時顯示需要幾滴水、已澆幾滴，以及大樹現在長成的樣子。
彩排時可以先「模擬加入」幾人，再按「💧 模擬澆水（看完成的樹）」，就能直接看到長成的大樹；「清除澆水」可以重來。
